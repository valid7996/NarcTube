# NarcTube

NarcTube is a lightweight Android app prototype for downloading YouTube videos and audio in different qualities.

## Features

- Paste a YouTube URL
- Choose between video and audio
- Select quality
- Simulated progress and status flow
- Download action and reset button

## Project structure

- `app/` contains the Android application code
- `MainActivity.kt` is the main screen
- `NarcTubeViewModel.kt` holds the app state and simulation logic
- `Theme.kt` defines the app theme

## Run

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or device.

## Notes

This is a prototype app and not a full legal YouTube downloader implementation. It demonstrates the UI and workflow for an Android downloader app.
